# Workflow: Prompt Structure Execution

## Steps
1. Create/refine tactical TODO.
2. Classify complexity (`small|medium|big`).
3. Run Plan Review Gate for `medium|big`.
4. Freeze decision baseline (`D-01`, `D-02`, ...).
5. Request explicit approval.
6. Implement within scope.
7. Validate and produce Decision Adherence table.
8. Block delivery on unresolved `Exception` decisions.

## Output
- Approved TODO
- Frozen baseline
- Decision adherence table with evidence
