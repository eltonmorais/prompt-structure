# Cline Authority Boundary

## Use When
- Multiple planning sources exist (assistant proposals, external suggestions, tool plans).

## Rules
- Planning and recommendations are advisory.
- Delivery authority is the execution contract:
  - tactical TODO,
  - explicit approval,
  - decision adherence evidence.
- No approved contract, no implementation.
- Unresolved decision exception means no delivery.

## Output
- Clear separation between advisory planning and authoritative execution.
