# Decision Baseline Freeze

## Use When
- Plan review is complete and implementation is about to start.

## Procedure
1. Assign stable IDs (`D-01`, `D-02`, ...).
2. For each decision, record expected outcome.
3. Move decisions into a `Decision Baseline (Frozen)` section.
4. Do not start implementation without explicit approval.

## Output
- Frozen decision list that delivery must satisfy.
