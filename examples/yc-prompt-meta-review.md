# Meta-Review Example: YC Prompt

## Strengths
- Good review taxonomy (architecture/code/tests/perf).
- Explicit tradeoff mindset.
- Interactive sequencing.

## Gaps
- Prompt-only enforcement is weak for complex execution.
- Missing decision freeze and adherence gate.
- No clear authority model for planner vs executor.

## Upgraded Decisions (Example)
- `#1 = C`: prompt as strategy, execution in skills/workflows.
- `#2 = B`: evidence/options/effort/risk mandatory.
- `#3 = C`: decision adherence table mandatory; unresolved exceptions block delivery.
- `#4 = Cline way`: planning advisory, execution contract authoritative.
